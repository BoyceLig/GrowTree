5 个候选 · 都从封面「晨光森林」的薄荷绿系里取

封面（登录页）用的是 #f0faf4 → #e4f5ec → #d8efe3 + 一抹 rgba(136,214,178,.38) 的顶部光。 G1 就是把这套原封不动搬到整页，G2~G5 是在同一色系里往深、往浅、往暖、往冷各走一步，你可以直接对比差异。

两点说明

  • 文字为什么跟着主题走？蓝底/绿底配深褐字会有一点暖冷打架，配同族色相的深字更干净：男孩蓝用深海军蓝字（#1e3a57 主 / #3d5f80 次 / #5c7d9c 弱），家长绿用深松绿字（#1f4736 主 / #3d6a54 次 / #5d8570 弱）。所有正文色在最浅与最深的候选底上对比度都 ≥ 6:1（远高于 4.5:1 达标线）；橄榄田 G4 单独换成橄榄字、深海蓝 B3 / 深松林 G5 因底最深字再压半档，卡片阴影也从暖褐改成随主题冷暖。上方切换键仍可对照「沿用深褐（只改背景）」的效果。
  • 家长端现在还没有主题，所有家长页面（总览 / 任务 / 积分 / 成长 / 商城 / 审核 / 流水 / 树洞 / 我的 / 加购 / 帮助…）统一走粉色。选定后我会把它们整体切到绿色，孩子端那 4 个 tab 继续按性别（女孩粉 / 男孩蓝），「我的」这种两端共用的页面按当前身份自动变。
