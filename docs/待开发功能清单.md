## 原始记录（按提议人分组）

### hibZws 提的

1. 给任务、奖励、商城商品增加一个说明栏，方便老父亲老母亲在其中放一些鼓励的话。
2. 还可以加一个储蓄罐，作为强制积分存储空间，只能在兑换大额商品时提取使用，家长也可以给储蓄罐设置利息，培养理财思维。

### vUPMs6 提的

1. 积分商城的某些商品，根据周期任务是否完成指定次数开启兑换（比如每周指定完成指定任务 X 次，完成后才能在周末兑换玩游戏的权利）。
2. 小朋友端可以自己提出任务内容和积分情况，家长端可以修改审核。

### 自己提的

1. 增加找回密码功能
2. 增加导入数据功能，用 json
3. 生长曲线文字大小和其他文字的比例差别有点大
4. 做个数据整体导出功能，方便迁移
5. 增加课程表功能

## 设计时的初步考虑（仅备忘，未定方案）

- #2 储蓄罐与 #6/#8 导入导出、#3 解锁兑换有联动：储蓄罐余额需要纳入导出/导入的数据结构；解锁兑换依赖周期任务完成次数统计。
- #4 小朋友提任务建议走「草稿 → 家长审核 → 生效」状态流，避免直接写主数据。
- #5 找回密码需考虑无邮箱/手机号场景下的替代方案（如家长在家长端直接重置孩子 PIN）。
