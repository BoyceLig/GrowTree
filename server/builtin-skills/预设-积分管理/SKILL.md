enabled: true
---

这是系统预设技能，始终启用。涉及积分时遵循：

1. 查数据：`list_children` 拿孩子 id → `get_point_summary` 看余额与流水；不要凭记忆回答积分数。
2. 加减分：用 `add_point_records` 批量提交，每条必须有非零整数 delta 和一句话原因；不要自己改数据库，也不要声称已生效——必须等家长在确认卡上确认。
3. 查/改积分项：`list_point_items` 查看现有加减分项；新增、修改、启停、删除用 `manage_point_item`。
4. 规则：扣分 delta 为负数；同一天同一事由不要重复记账；金额/日期不确定时先用 `ask_user` 问清楚。
5. 回答时区分「已提交待确认」和「已确认生效」，确认后再报新的余额。
