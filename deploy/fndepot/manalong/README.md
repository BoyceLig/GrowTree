# 🌳 满伴成长树 · ManAlong

> 面向家庭的自托管积分管理系统 —— 让孩子在完成任务、赚取积分、兑换奖励的过程中，学会规划与储蓄。

**怎么玩**：孩子完成日常任务，或家长发布的临时任务 → 获得积分 → 用积分在商店兑换商品或现金；
所有申请由家长审核把关。**数据全部保存在你自己的 NAS 上（SQLite 单文件），不上传任何云端。**

- 仓库：<https://github.com/BoyceLig/ManAlong>
- 作者：**BoyceLig**（微信 `Boyce_Lig`）

## 功能特性

### 👨‍👩‍👧 家长端

- **总览**：所有孩子的积分、今日变化、待审核数量；树洞信箱、悄悄话、审核都在这一页
- **任务**：临时任务（分类、积分奖励、截止时间）+ 周期任务（每天 / 每周，可「多天只完成一次」）
- **积分**：设置日常加分 / 扣分项目（可限每日次数），一键为孩子加减分
- **审核**：任务完成、商品 / 现金兑换、心愿单集中审批
- **商城**：商品分类、库存，实物与道具两类，可上下架
- **背包**：网格化查看孩子物品，区分「孩子用的 / 家长送的 / 家长拿走的」，附操作历史
- **成长**：身高体重记录 + 中国儿童生长标准百分位曲线；支持多孩子按年龄对齐对比
- **日记**：成长日记：图文 / 视频混排，图片并排自适应、拖拽重排、拖边调占比（飞书式）
- **日历**：双端日历：日程按参与人归属，支持跨天与「开始 / 结束 / 时长」双向计算；公开 / 私有两档；家长可设重复「特殊日」，当天积分获得翻倍或消耗减半
- **记录 / 操作历史**：全部积分流水 + 家庭操作时间线（谁在何时做了什么）
- **账号**：多家长账号；家长与孩子两个身份可在同一浏览器并行登录

### 🧒 孩子端

- **主页**：积分余额、生肖头像、等级进度、今日积分、最近记录
- **任务**：领取任务、提交完成，等待家长审核
- **商城**：用积分兑换商品或申请兑换现金，道具直接进背包
- **成长 / 日记**：看自己的成长曲线和自己的成长日记
- **日历**：自己的日程 + 兄弟姐妹的日程（私有日程只显示「私有日程」占位与时间）
- **小心思**：树洞信箱（家庭留言墙）、悄悄话（和家长一对一私聊）、心愿单（许愿 → 家长审核 → 上架）
- **背包**：自己拥有的道具、已使用的、被家长拿走的（含理由与返还积分）

### ✨ 其他

- 家长用账号 + 密码登录；孩子用账号 + PIN 码登录（无需记密码）
- 内置 12 生肖头像；WebSocket 实时推送
- 响应式设计，手机 / 平板 / 电脑均可使用
- 可自定义兑换比例（默认 10 积分 = 1 元）
- 图片 / 视频上传按哈希去重

## 安装说明

**方式一：FnDepot 第三方商店（推荐）**

在 FnDepot 应用里「源管理 → 添加源」，填入 FnDepot 源地址后同步，即可搜索「满伴成长树」一键安装。

**方式二：应用中心手动安装**

在飞牛应用中心 → 手动安装本应用包后：

1. 桌面出现「满伴成长树」图标，点击即可打开
2. 默认管理员账号：`admin` / `admin123` —— **请登录后立刻在「设置」里改密码**
3. 在家长端添加孩子账号、设置孩子 PIN 码，即可开始使用

> 默认服务端口为 **3000**，如与现有应用冲突，可在应用设置里调整。
> 数据存放在系统托管的应用数据目录中，**升级、覆盖安装都不会丢数据**。

## 常见问题

**安装后一直停在“启动中” / 提示拉取镜像失败？**

首次安装需要拉取约 200 MB 的镜像，国内网络偶尔会慢或超时。可以：

1. 在飞牛「Docker → 设置 → 镜像加速」里配置一个可用的加速地址后重试
2. 或在应用中心里对「满伴成长树」执行一次「停止 → 启动」，让 Docker 重试拉取
3. 已配置代理的用户，可在 Docker 的代理设置中填自己的代理地址

本应用的镜像由本仓库构建（构建与发布方式见根目录 [README](https://github.com/BoyceLig/ManAlong#readme) 与 `scripts/`）。

**端口冲突怎么办？** 默认占用 3000，如与本机其他应用冲突，可在应用设置里修改端口映射。

**数据存在哪？** 由飞牛托管在应用数据目录，升级、覆盖安装都不会丢；卸载时可按提示选择是否保留。
